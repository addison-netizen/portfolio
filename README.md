# Addison — Personal portfolio

A responsive, buildless portfolio for independent website design and development.

## Edit
Open index.html to update content and styles. No dependencies or build step are required. The two showcased designs are explicitly labeled fictional concepts.

## Deploy on Netlify
Import this repository into your personal Netlify account. Leave the build command empty and set the publish directory to `.`. netlify.toml includes these settings. Netlify will deploy updates pushed to main.
